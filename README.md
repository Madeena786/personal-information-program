# **Personal information program**



**DESCRIPTION:**

This is a simple python program to print the basic personal information from the user input format and display it in a clean formatted profile.



**OBJECTIVES:**

Here I learn:

* variables
* input() method
* type conversion
* formatted output
* f-strings



**INPUTS:**

The program has follow information from the users:

* Name
* Age
* Email
* Phone Number
* City
* Course



**OUTPUTS:**

The program displays the entered information in a formatted personal profile.



**TECHNOLOGIES USED:**

* Python
* Idle



**HOW TO RUN:**

1. open the file "personaldetails.py" using python idle.
2. click "Run" and select "Run Module" or press "F5".
3. Enter the required Information.
4. The personal profile will be displayed in the python shell.
